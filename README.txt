『상사(相思): 청평사의 뱀』 — 실행 방법
=====================================
1) 이 폴더 전체(index.html, game.js, story.js, assets/)를 그대로 둔 채,
2) index.html 을 더블클릭하면 브라우저에서 바로 실행됩니다. (Chrome / Edge 권장)
   - 파일로 직접 열었을 때 영상/음성이 안 나오면, 폴더에서 아래 명령으로 로컬 서버를 띄운 뒤
     http://localhost:8000 으로 접속하세요:   python -m http.server 8000
3) 조작: 대화 진행 = 클릭 / Space / Enter,  전투 = 숫자 1~5 (또는 D F G H J), 화면 원 클릭
   붉은 '怨' 구슬은 아무 키나 눌러 막습니다. 장단 10연속마다 오방 기술 컷인이 터집니다.
4) 진행 기록은 브라우저에 자동 저장됩니다. (타이틀의 '이어서 / 장 선택 / 갤러리')
